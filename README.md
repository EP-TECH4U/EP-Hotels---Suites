# 🏨 EP Hotels & Suites

A modern, responsive, and user-friendly hotel website designed to showcase luxury accommodations, premium services, and seamless guest experiences.

## 📖 Overview

EP Hotels & Suites is a front-end web development project created to provide an elegant online presence for a hospitality brand. The website enables visitors to explore hotel rooms, amenities, services, and contact information through an intuitive and visually appealing interface.

The project focuses on responsive design, accessibility, and a smooth user experience across desktop, tablet, and mobile devices.

## ✨ Features

* Responsive and mobile-friendly design
* Modern and professional user interface
* Hotel room showcase
* Services and amenities section
* Contact and reservation information
* Smooth navigation experience
* Clean and organized layout
* Optimized for multiple screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 Project Objectives

The goal of this project is to demonstrate practical front-end web development skills by building a realistic hotel website that combines functionality, aesthetics, and usability.

This project highlights:

* Responsive Web Design
* User Interface Design
* Website Structure and Layout
* Front-End Development Best Practices

## 🚀 Getting Started

1. Clone the repository:

   ```bash
       https://github.com/EP-TECH4U/EP-Hotels---Suites
   ```

2. Open the project folder.

3. Launch `index.html` in your browser.
